순서: 주작·현무·백호·청룡·기린 · 현재 보유량 qᵢ의 부족량 dᵢ=max(0,50−qᵢ) · 아래 ⌈x⌉는 올림

기린이 완료된 상태의 저격 횟수:
N(d) = ⌈max(d주, d현) / 2⌉ + ⌈max(d백, d청) / 2⌉

상태 전이:
T50(d): 주작·현무 부족량 각각 2 감소
T80(d): 백호·청룡 부족량 각각 2 감소
T100,i(d): 기린 부족량 2 감소 + 상자 종류 i 부족량 5 감소
모든 부족량은 0 아래로 내려가지 않음.

최적 평균 남은 횟수:
V(0,0,0,0,0) = 0
V(d) = min { 1+V(T50(d)),
             1+V(T80(d)),
             1+(1/5)Σᵢ V(T100,i(d)) }

상자로 상태가 그대로인 경우 처리:
상태를 바꾸지 않는 결과가 r개라면,
Q상자(d) = [5 + Σ(상태가 바뀌는 결과의 V)] / (5−r)
저격 두 구간의 비용과 Q상자를 비교한다.
r=5이면 진행이 없으므로 그 선택은 제외한다.

저격 우선 전략의 평균:
B(d) = N(d)                         (기린 부족량=0)
B(d) = 1+(1/5)Σᵢ B(T100,i(d))       (기린 부족량>0)
