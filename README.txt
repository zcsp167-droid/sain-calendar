사인검 제작 달력

거상 사인검 제작에 필요한 임무 재료(삼인검 석판 · 사인검 X옥 조각) 수집 일정표
현재 보유량과 접속 가능 시간 기준으로 다음 임무 추천 · 재료 확보 예상일 산정

■ 받기와 실행
· 받기: 이 저장소 오른쪽 'Releases' → 최신 버전 → Assets의 SainCalendar-(버전).zip
· Assets의 'Source code (zip)' · 'Source code (tar.gz)'는 GitHub가 자동으로 붙이는 소스 묶음 · 받을 필요 없음
· 다운로드 시 브라우저의 '자주 다운로드되지 않는 파일' 경고: 처음 배포 파일에 흔한 경고 · '유지'(또는 '계속') 선택
· zip 안 구성: SainCalendar-(버전)-portable.exe(프로그램) · 제거.bat(완전 제거) · 사용설명서.txt(이 내용과 같음)
· 압축 해제 후 SainCalendar-(버전)-portable.exe 실행 · 설치 없음 · Node.js 등 다른 프로그램 불필요
· 실행할 때마다 준비 과정이 있어 창 표시까지 몇 초 소요 가능
· 기능별 사용법: 프로그램 오른쪽 위 '설명서'

■ 처음 사용
1. 실행 시 초기설정 창 자동 표시
2. 접속 시간 → 삼인검 보유 → 사인검 임무 가능 여부 → 보유 재료 → 진행 중 임무 → 알림 → 단축 방식 순서로 입력
3. 마지막 단계 '저장 · 시작' 클릭

■ 기본 사용 흐름
· 게임에서 임무 발송 후 '임무 보내기' 클릭
· 임무 완료 후 게임에서 보상 수령 → '수령하기' 클릭 · 100% 임무는 상자에서 나온 석판 선택
· 일요일 수행서 · 금요일 철제검 퀘스트 완료 후 퀘스트 칸 '수령' 클릭
· 보유량 · 설정값: 더블클릭으로 수정
· 접속 못 하는 날: 달력 '접속 불가' 클릭 후 날짜 선택 · '적용'
· 귀서 · 임달 사용량 조정: 메인 '효율설정'

■ 투명한 배포 (작성자 PC에서 만들지 않음)
· exe는 작성자가 만든 파일이 아님 · 이 저장소의 공개 소스로 GitHub 서버가 직접 빌드
· exe에 들어가는 내용 = 저장소에 공개된 소스 전부 · 소스를 바꾸면 변경 기록(Commits)이 모두 공개
· 빌드 방법: .github/workflows/build.yml · 빌드 기록: 'Actions' 탭 · 결과물: 'Releases'('github-actions' 표시)
· 빌드 증명서: 'Attestations'에서 exe가 이 저장소 소스로 만들어졌는지 확인 가능
· Releases 잠금: 한 번 공개한 exe · zip은 작성자도 교체 · 삭제 불가(GitHub 기능) · 받은 파일 = 처음 공개된 파일
· 직접 확인: Fork → Actions → Build exe → Run workflow로 같은 소스를 직접 빌드 가능

■ 안전 확인
· 인터넷 연결 기능 없음 · 개인정보 · 기록 외부 전송 없음 · 자동 업데이트 없음
· 게임 파일 · 게임 프로그램 접근 없음 · 게임 자동 조작 없음
· 저장 위치: %APPDATA%\personal-calendar 한 곳 + 사용자가 직접 고른 백업 파일
· '자동 실행' 켤 때만 Windows 시작 프로그램 등록

■ 바이러스토탈(VirusTotal)로 직접 검사
· 작성자 검사 결과 대신 받은 파일을 직접 검사 권장
1. 브라우저에서 virustotal.com 접속
2. 'FILE' 탭 → 'Choose file' → 받은 SainCalendar-(버전)-portable.exe 선택 (제거.bat도 같은 방법으로 검사 가능)
3. 1~2분 대기 → 결과 화면 위쪽 숫자 확인 · 예: 0/70 = 백신 70개 중 탐지 0개
4. 결과 읽는 법
   · 0개: 탐지 없음
   · 1~2개: 유료 인증서 서명 없는 프로그램에 흔한 오탐 가능 · 아래 목록에서 탐지한 백신 이름 확인
   · 이미 누군가 검사한 파일이면 이전 결과 바로 표시 · 'Reanalyze'로 다시 검사 가능
5. 결과 화면 주소(링크)를 저장해 두면 언제든 다시 확인 가능
· 참고: VirusTotal에 올린 파일은 보안 업체들과 공유됨 · 공개 배포 프로그램이라 문제 없음

■ 받은 파일 확인 (공식 배포 파일과 같은지)
1. 받은 zip이 있는 폴더의 빈 곳에서 Shift + 오른쪽 클릭 → 'PowerShell 창 열기'(또는 '터미널에서 열기')
2. 아래 명령 입력 후 Enter (파일 이름은 받은 버전에 맞게)
   Get-FileHash .\SainCalendar-(버전).zip
3. 나온 Hash 값과 Releases 페이지 zip 파일 옆 sha256 값 비교 · 같으면 같은 파일(대소문자 무관)

■ 실행 문제
· 'Windows의 PC 보호' 창: 유료 인증서 서명 없는 무료 프로그램이라 표시 가능 → '추가 정보' → '실행'
· '스마트 앱 컨트롤이 안전하지 않을 수 있는 앱을 차단했습니다' 창: 서명 없는 프로그램을 막는 Windows 기능 · 이 PC에서는 실행 불가
  - 인증서는 매년 갱신 · 연 십수만 원 이상 비용 · 무료 배포라 서명하지 않음
  - Windows 보안 → 앱 및 브라우저 컨트롤 → 스마트 앱 컨트롤 설정에서 끄기 가능 · 끄는 것은 본인 판단
  - 최신 업데이트가 적용된 Windows 11은 끈 뒤에도 같은 곳에서 다시 켜기 가능
· 자동 실행을 켠 뒤 exe를 다른 폴더로 옮긴 경우: 프로그램에서 자동 실행을 한 번 껐다 다시 켜기
· 화면에 영어 코드 글자가 보이는 경우: 사용 중인 화면 번역 기능(번역 프로그램 등) 끄기

■ 데이터와 백업
· 설정과 내부 백업 저장 위치: %APPDATA%\personal-calendar
· 중요한 기록은 프로그램 '저장·불러오기'에서 별도 파일로 백업
· exe만 삭제하면 저장 데이터는 남음

■ 완전 제거
1. 프로그램 완전 종료(트레이 아이콘 포함)
2. 함께 들어 있는 제거.bat 실행
3. 삭제 경로 확인 후 DELETE 입력(대소문자 무관) → 자동 실행 등록과 설정 · 내부 백업 삭제
4. '제거 완료' 표시 후 프로그램 폴더 삭제
· 직접 다른 곳에 저장한 백업 파일은 삭제 안 함

■ 주의
· 게임 자동 진행 프로그램 아님 · 모든 결과 직접 기록 필요
· 표시 날짜는 예상값 · 상자 보상 · 실제 접속에 따라 변동
· 알림은 프로그램 실행 중에만 동작
· 현재 버전이 최종본 · 업데이트 · 오류 제보 미접수
· 무료 프로그램 · 무단 복제 · 배포 · 판매 금지

■ 저장소의 기타 파일
· 1_install.bat · 2_run.bat · 3_register_startup.bat · start-app.bat · run-hidden.vbs: 소스 그대로 실행하는 개발용(Node.js 필요) · 일반 사용자는 zip의 exe 사용
· verification 폴더: 계산 검증용 코드
